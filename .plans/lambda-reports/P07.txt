The default stays the harmless preview. Nothing that used to be fake became live.
Changed defaults: bare `pnpm dev` no longer starts the real agent; `start.sh`/`preview`
ignore an inherited GAZE_AGENT_CMD (it used to run, even if it was the real agent).

Live details:
- Electron main starts the real agent only when the launcher's own environment has
  GAZE_AGENT_MODE=live and GAZE_AGENT_CMD is empty. GAZE_AGENT_MODE is read before .env is
  loaded, so .env cannot switch on desktop control. Modes: live | preview | custom.
- Precedence (unchanged): a variable set in the shell (even empty) beats .env (dotenv does
  not override). The live launcher sets DEMO_MODE=1 and GAZE_SOURCE=mouse unless they are
  set in the SHELL; their .env values are ignored, as before. Model/effort/REPLAY/key: shell,
  else .env; no code defaults were added or changed (.env.example untouched).
- Preflight, before anything starts (shell): OPENAI_API_KEY must be present in the shell or
  .env unless REPLAY=replay. Electron main repeats the full check before creating a window
  or spawning anything: key (unless REPLAY=replay), OPENAI_MODEL_AGENT/FAST/VISION set,
  OPENAI_REASONING_EFFORT_* valid if set, REPLAY in off|record|replay, DEMO_MODE 0|1, and
  no GAZE_AGENT_CMD. Any problem -> messages naming the variable (never its value), exit 1.
- Terminal disclosure: start.sh prints "LIVE: the real agent calls OpenAI and clicks and
  types on this Mac" with DEMO_MODE/GAZE_SOURCE/REPLAY (approved values only, otherwise
  "invalid"). Main prints "[agent] LIVE: real Python agent on 127.0.0.1:<port>", REPLAY,
  DEMO_MODE, key set/unset, efforts, and which live settings the shell overrides over .env.
  Never printed: key, token, custom command.
- Preview: the fake agent child no longer receives OPENAI_API_KEY/OPENAI_ADMIN_KEY/
  AZURE_OPENAI_API_KEY. Custom and live receive the full environment.

4. REPRODUCED BUGS VS HYPOTHESES
--------------------------------
Reproduced with stubs/fakes (old scripts from HEAD run against the new tests' stubs):
  A. `start.sh real` rejected a key that was set only in the shell, although Electron and
     the agent would use it ("No OPENAI_API_KEY in .env", exit 1).
  B. `start.sh real` accepted OPENAI_API_KEY="" (also `=   # comment`) and launched Electron
     and the real agent; every model call would then fail.
  C. `start.sh` / `start.sh fake` ran an inherited GAZE_AGENT_CMD: with the real agent's
     command the "fake" preview became live (pnpm dev got CMD=uv run ... gaze_agent.server).
  D. An unknown mode ran `pnpm install` before printing usage.
  E. `dev-browser.sh stop` could not stop a leftover real agent or Electron overlay.
  F. Real backend: AutoWatcher swallows a failed explicit refresh (LLMError, e.g. missing
     key) into last_error and Session.dispatch sends nothing for auto_refresh, so the
     overlay showed "Thinking…" forever. Reproduced with fakes (isolation guard, fake
     llm.complete raising LLMError; nothing emitted, last_error == "LLMError").
  G. Fake agent (and real backend by code reading): a second auto_refresh within 3 s gets no
     reply at all. Reproduced against fake_agent.py on a free port: "NO REPLY after 4 s".
     A quick re-dwell or Auto tab round-trip therefore hung the Suggest now spinner.
Found by code reading (fixed; behavior covered by unit tests, not observed natively):
  H. Bare `pnpm dev` silently spawned the real agent (resolveAgentCommand default).
  I. Agent exit/spawn failure (uv missing -> exit 127, port taken, crash) was only logged
     for 'error'; the overlay stayed on "Connecting…/Reconnecting…" forever.
  J. Quit sent SIGTERM right after closing the socket; Python dies on SIGTERM without
     running `finally` (no release_keys). Electron also may exit without stopping its
     detached agent group.
Hypotheses (NOT verified; need the human):
  - Electron runs `before-quit` on Ctrl+C/SIGTERM (electron-vite forwards SIGINT/TERM/HUP to
    Electron); if not, the process 'exit' SIGKILL safety net or `scripts/start.sh stop` is
    the fallback.
  - The real agent on SIGINT cancels its main task, closes sessions and releases keys
    (asyncio.run + KeyboardInterrupt, websockets server close). If it does not, SIGTERM/
    SIGKILL follow within 3.5 s.
