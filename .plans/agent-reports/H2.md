## Interface and integration

`gaze_agent.tools.launch.LaunchProvider` implements H1's async `prepare`/`execute`
contract, importing `ActionRequest`, `PreparedAction`, `ActionResult` directly.
Checked against published H1 revision `de01ea803c387f2b6596bcdcd3149de544627ff9`
on `structured-action-provide-983636d1`; no contract mismatch found.
Those shared files are absent from this base: coordinator must integrate H1's
contracts and initializer before runtime imports. H2 did not copy them into the
repository or edit shared files. H1 owns registration/composition and schemas.

Register one `LaunchProvider()` instance for `app.open` and `web.open`.
Provider identifier: `system_launcher`.

- `app.open {name}` accepts case-insensitive Safari, Mail, Messages, TextEdit,
  Notes, Calendar; freezes canonical `{name}` in the prepared payload. Executes
  `/usr/bin/open -b <fixed bundle identifier>`.
- `web.open {url}` preserves the exact validated URL in `{url}`. Executes
  `/usr/bin/open <url>` without shell expansion. Only HTTP(S), valid host/port,
  no credentials, controls, backslashes or malformed escapes. Raw whitespace,
  unsupported schemes, option injection and extra arguments are rejected.
  ASCII DNS, IPv4 and bracketed IPv6 hosts are supported; use punycode for IDNs.
- `prepare` rejects invalid input with fixed `ValueError` codes and performs no
  I/O. `execute` revalidates provider/payload, rejects noncanonical/forged payloads,
  and returns structured outcomes. H1 must still enforce URL risk/confirmation,
  including checkout/payment URLs, task state and request deduplication.
- Success: `completed / launcher_accepted`, meaning only exit zero from the
  launcher. Nonzero: `failed / launcher_rejected`. Missing/denied launcher:
  `failed / launcher_unavailable`. Timeout: `unknown / launcher_timeout`.
  Unexpected post-dispatch errors: `unknown / launcher_error`.
  No raw error, stdout/stderr, URL or provider receipt is returned/logged.
- Default launch deadline 5 seconds; cleanup waits 0.5 seconds each, then kill
  fallback. Cancellation propagates after terminate/reap and survives repeated
  cancellation. Creation races retain ownership of the eventual child. A broken
  transport that never completes creation cannot be synchronously reaped; late
  completion triggers cleanup. A killed process with a broken wait transport
  retains a background waiter. No automatic launch retry is implemented.

Injection: `LaunchProvider(process_transport=async_create_process,
timeout=5.0, cleanup_timeout=0.5)`. Transport receives argument vectors and
`stdin/stdout/stderr=asyncio.subprocess.DEVNULL`; process supplies async `wait()`,
`terminate()`, `kill()`. Import/construction do not inspect configuration,
permissions, accounts or installed apps. No new dependencies.
